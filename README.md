# ZenRadio Kodi add-on

Unofficial community add-on for listening to ZenRadio through Kodi with an AudioAddict account.

## Features

- Browse all ZenRadio channels
- Browse styles, popular and new channels
- Synchronise favourites with the AudioAddict account
- Select Premium stream quality
- Dynamic Now Playing metadata in Kodi
- Background metadata updates
- Session reuse with credential fingerprinting
- Bounded stream-server probing with conservative fallback
- English and French localisation

## Status

Version 0.9.0 is a local test build. It is intended to be validated on Kodi before the first public 1.0.0 submission.

## Disclaimer

Unofficial community add-on. Not affiliated with, endorsed by, or supported by ZenRadio or AudioAddict. Original community artwork is used instead of the official ZenRadio logo.
